> [!abstract] What is Cybersecurity?
> The practice of protecting **information, systems, networks, devices, and people** by ensuring three core properties — Confidentiality, Integrity, and Availability — known as the **CIA Triad**.

---

# Core Concepts

## Security Analyst

> [!note] Role
> A security analyst monitors systems for security incidents and helps protect an organization's infrastructure.

**Responsibilities**
- Monitor networks for breaches
- Investigate security incidents
- Develop security strategies
- Research emerging threats
- Prevent attacks before they occur

---

## Compliance

Following internal policies and external laws or regulations.

| Purpose | Why it Matters |
|---------|----------------|
| Avoid legal penalties | Non-compliance can result in fines or prosecution |
| Meet industry standards | Builds trust with customers and partners |
| Reduce security risks | Policies force security baselines to be maintained |

---

## Security Frameworks

Guidelines and best practices used to design and manage an organization's security program.

| Framework | Focus |
|-----------|-------|
| NIST Cybersecurity Framework | Risk management and security improvements |
| ISO/IEC 27001 | Information security management systems |
| CIS Controls | Prioritized security actions |

---

## Security Controls

Protective measures implemented to reduce security risks.

| Type | Examples |
|------|---------|
| Administrative | Security policies, training programs |
| Technical | Firewalls, MFA, IDS |
| Physical | Security cameras, access cards |

---

## Security Posture

> [!info] Definition
> An organization's overall ability to protect its systems and respond to threats.

A strong security posture requires:
- Regular software updates
- Employee security training
- Continuous monitoring
- Documented incident response plans

---

# Threat Actors

Any person or group capable of causing harm to systems or data.

> [!warning] Internal Threat
> A **trusted insider** — employee, contractor, or vendor — who unintentionally or deliberately creates a security risk. These are especially dangerous because they already have authorized access.

**Accidental:** Clicking phishing links, weak passwords, misconfigured systems
**Intentional:** Data theft, privilege abuse, corporate espionage

---

# Network Security

Protecting an organization's network from unauthorized access and attacks.

Protects: devices, servers, services, data, and network traffic.

Common tools: Firewalls, VPNs, Intrusion Detection Systems (IDS)

---

# Cloud Security

Protecting cloud-hosted data, applications, and infrastructure.

Focus areas: secure configuration, access control, data protection, identity management.

Examples: AWS Security, Azure Security, Google Cloud Security

---

# Programming in Cybersecurity

Programming allows analysts to automate repetitive tasks such as log analysis, threat detection, malware analysis, and web traffic inspection.

| Language | Common Use |
|----------|-----------|
| Python | Automation, scripting, analysis |
| PowerShell | Windows system administration |
| Bash | Linux automation |
| JavaScript | Web security, browser analysis |
| Go | High-performance security tools |

# Exam Tips

> [!tip] Remember These Distinctions
> - **Framework** = the plan / guidelines
> - **Control** = the actual protection measure
> - **Posture** = how strong your overall security is
> - **Compliance** = following the rules
> - **Threat Actor** = the attacker
> - **Internal Threat** = an attacker already inside
